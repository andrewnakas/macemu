# Ricochet (Macintosh charityware, 1996–1999)

## What this is

Ricochet, by Bob Urschel — a Macintosh puzzle game in which a runner crosses
the board on its own and the player turns it with the left and right arrow
keys, relative to its direction of travel, to hit every target on the level.

## Rights

Charityware: shareware whose registration fee went to a national 501(c)(3)
non-profit. The licence, in the game's own documentation (Credits → Legal
Stuff), reads in part:

> Non-profit distribution of this software is acceptable without prior
> written notice, providing that the software is not modified in any way, and
> the complete works of the software are included in the distribution package.

This site is non-profit and carries no advertising. The copy is the
unregistered release — fifteen levels, editor locked — with the application,
the DOCMaker manual and the high-score file all present and unmodified. The
charityware notice at startup is left in place.

## Provenance

Internet Archive item `tucows_205663_Ricochet`, from the Tucows Macintosh
archive. The `.sit` expands to a plain folder, copied onto a title disk that
mounts beside the shared Mac OS 8.6 image.
On that disk the application file is named "Start App" (with an alias,
"Start") so the shared system can launch it at boot; its contents are
byte-for-byte the archived original.
