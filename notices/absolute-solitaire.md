# Absolute Solitaire (MacSoft / Varcon Systems) — Macintosh

## What this is

**The demo build** of Absolute Solitaire, published by MacSoft from the Varcon
Game Collection — a solitaire package for the classic Macintosh. The title
screen carries "DEMO" across it in red, which is left exactly as it is.

The full version was sold; this is the copy Varcon gave away.

## Licence

A freely distributed demo, used here for what it was made for. It is
unregistered and unmodified, and its own demo branding is intact.

MacSoft's catalogue passed through WizardWorks and Infogrames; Varcon Systems
is no longer trading. No current product contains this program and it has not
been sold in around two decades.

## Provenance

Internet Archive item `tucows_205768_Absolute_Solitaire`, from the Tucows
Macintosh archive. The `.sit` expands to a plain folder, copied onto a title
disk that mounts beside the shared Mac OS 8.6 image.

On the title disk that mounts beside the shared Mac OS 8.6 image, the
application file is named "Start App" (with an alias, "Start") so the shared
system can launch it at boot. Only the file's name was changed; its contents
were copied unaltered.
