# Hardwood Solitaire II (Silver Creek Entertainment, 1999) — Macintosh

## What this is

Hardwood Solitaire II, the PowerPC Macintosh build, published by Silver Creek
Entertainment — solitaire with rendered wooden table art and card backs.

It runs in 256-colour mode and offers to change the monitor's depth on
startup, restoring it when you quit.

## Rights

Silver Creek Entertainment still exists and still sells card games — Hardwood
Solitaire is a line that has continued through several generations on modern
platforms.

That is a live company with a live product line, and it is said plainly. What
is hosted is the 1999 **classic Mac OS** build, which is in none of those
current products and has not been sold in around twenty-five years. Because
the publisher is active and reachable, this is one of the easier takedowns on
the site to honour and it will be honoured immediately on request.

## Provenance

Internet Archive item `tucows_205788_Hardwood_Solitaire_II`, from the Tucows
Macintosh archive. The `.sit` expands to a plain folder, copied onto a title
disk that mounts beside the shared Mac OS 8.6 image.

On the title disk that mounts beside the shared Mac OS 8.6 image, the
application file is named "Start App" (with an alias, "Start") so the shared
system can launch it at boot. Only the file's name was changed; its contents
were copied unaltered.
