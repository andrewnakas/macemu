# Barrack (Ambrosia Software, 1996) — Macintosh

## What this is

Barrack 1.0.4, published by Ambrosia Software — exactly as the Ambrosia
installer produced it.

## Licence

Ambrosia shareware, under the same agreement as Avara, Cythera and Ferazel's
Wand:

> Non-profit distribution of the software is acceptable without prior written
> notice, providing that the software is not modified in any way, and the
> complete works of the software are included in the distribution package.

Both conditions are met. The copy is what the installer wrote — the game, its
sprites, sounds, music, titles, the contest file and the documentation — and
the unregistered shareware notice it shows at startup is left exactly where it
is.

As with the other Ambrosia titles: the permission is for *non-profit*
distribution. **If macemu ever carries advertising, these have to be
revisited.**

## Provenance

Internet Archive item `tucows_205647_Barrack`, from the Tucows Macintosh archive
— `barrack.sit`, which expands to an Installer VISE archive (`SVCT`) that no
tool outside a Mac reads. The installer was run inside emulated Mac OS 8.6 and
the result taken back out; see `scripts/author-disk.mjs`.

The game is mounted beside a shared Mac OS 8.6 image rather than carrying its
own copy of the operating system.
