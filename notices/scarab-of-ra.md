## Provenance

Internet Archive item `ScarabOfRaMacintosh`, file `ScarabOfRa.img`: an HFS
disk holding a System 7 System Folder and the "Scarab of RA 1.4" folder
(the application and its "Dean's List" high-score file). The folder's
contents were copied onto a System 7.5.3 boot disk, into Startup Items so the
game finds its file beside it, by `scripts/add-from-archive.py`.

Played on 2026-09-27: boots into the entrance of the Great Pyramid.
