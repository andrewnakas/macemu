# SimTower (Maxis / OPeNBooK, 1994) — Macintosh

**Hosted:** yes, as `simtower-title` beside the shared Mac OS 8.6 image.

## What this is

SimTower version 1.2 for Macintosh (its readme is dated 24 April 1995),
designed by Yoot Saito, developed by OPeNBooK and published by Maxis.

## Rights

Maxis was bought by Electronic Arts in 1997; the design is Yoot Saito's.
EA has sold many Maxis games since, but this Macintosh release of SimTower has
not been sold for decades and is not part of any current product. It is
preserved here on the same practical footing as SimCity and SimEarth on this
site: a position, not a legal claim.

If Electronic Arts or Yoot Saito asks, it goes the same day.

## Provenance

Internet Archive item `SimTowerMacOS`: a raw MODE1/2352 image of the
Macintosh CD. The 2048-byte sectors were extracted and its HFS volume read.
The CD holds one installer, "SimTower Install" (Installer VISE), plus a Maxis
CD-ROM Sampler that is not included here.

The installer was run inside the emulated Mac (Mac OS 8.6), installing to an
empty work disk; the resulting "SimTower" folder (the application, "Read Me
First!" and Maxis's Electronic Registration application) was copied onto the
title disk unaltered. Steps: `scripts/steps/simtower.json`.

On the title disk the application is named "Start App", with an alias "Start",
so the shared system can launch it at boot. Only the name changed.

Played on 2026-09-27: the 256-colour prompt, the title screen, and a new tower.
