# Deco (Monkey Byte Development, 1997) — Macintosh

## What this is

Deco, published by Monkey Byte Development — a falling-block puzzle game for
the classic Macintosh.

On startup it says the copy is unregistered, gives the order line and web
address, and offers "Not Yet" to carry on playing. Registering unlocked the
high-score display and removed the reminder; the game itself is not crippled.

That notice is the author's and is left exactly where it is, order line
included.

## Licence

Shareware, distributed freely with a registration reminder and no feature lock on
play. The copy here is unregistered and unmodified.

## Provenance

Internet Archive item `tucows_205666_Deco`, from the Tucows Macintosh archive.
The `.sit` expands to a plain folder, copied onto a title disk that mounts
beside the shared Mac OS 8.6 image.
