# Domain (Mike Perry, 1996) — Macintosh

## What this is

Domain 1.0 by Mike Perry — a Macintosh strategy game in which you take
territory on a 3D grid against a computer or network opponent.

## Licence

Shareware. The copy here is unregistered and unmodified: the registration
notice the program shows is exactly where the author put it, and the
documentation that came with it travels with the game.

Shareware of this era was distributed freely by design — that was the point of
the model, and the author's own read-me asks for the software to be passed on
intact. That is what has been done.

## Provenance

Internet Archive item `tucows_205636_Domain`, from the Tucows Macintosh
archive. The `.sit` expands to a plain folder, which was copied onto a small
title disk; it mounts beside the shared Mac OS 8.6 image rather than carrying
its own copy of the operating system.
