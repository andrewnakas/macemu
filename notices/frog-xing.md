# Frog Xing (Macintosh shareware, 1998)

## What this is

Frog Xing 1.6 — a Macintosh road-crossing arcade game in the Frogger mould.

It opens by asking to set the monitor to 256 colours or greys "for maximum
performance", offering Switch to 256, Don't Switch, or Exit — and promising to
restore the original setting when you quit. Unusually among the games here, it
will run either way.

## Rights

Worth naming: **Frogger is Konami's**, it is actively licensed, and
re-releases are sold today. This is not that game. It is an independently
written Macintosh shareware title in the same genre, with its own name, code
and artwork.

The resemblance is of genre rather than of assets, which is a more comfortable
position than Bub And Bob's borrowed name — but if Konami or a licensee
disagrees, it comes down on request.

As software, it is shareware, unregistered and unmodified.
