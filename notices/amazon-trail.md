# The Amazon Trail (MECC) — Macintosh CD

## What this is

MECC's The Amazon Trail CD for Macintosh, version 1.1 (copyright 1996), run
here on an emulated Power Macintosh under the shared Mac OS 8.6 image.

## Rights

The disc carries MECC's standard licence, which does not grant
redistribution. MECC — the Minnesota Educational Computing Consortium — was
privatised in 1991, sold to SoftKey in 1995, folded into The Learning Company,
bought by Mattel in 1999 and sold on in 2000; the education catalogue
eventually reached Houghton Mifflin Harcourt.

The Amazon Trail has not been sold in any form for well over twenty years and
no current product contains it. The Oregon Trail name has been licensed for new
software since; The Amazon Trail has not.

## Why it is hosted

It is The Oregon Trail's sibling from the same school computer labs, out of
commerce for decades and otherwise available only as an abandonware download.
It is hosted on the same footing as this site's Oregon Trail: a practical
preservation position, not a legal claim.

## Provenance

Internet Archive item `amazon-trail`, file `Amazon Trail.iso`: a hybrid
Macintosh/Windows CD (Apple partition map plus ISO 9660), volume "Amazon CD",
remastered at some point with Toast 5.1.1.

Only the Macintosh files were copied onto the title disk: the application
(`Amazon Trail CD`, PowerPC), its data files (`AMAZON.MMS`, `EFFECTS.SND`,
`IMAGES.PIC`, `VOICES.SND`, the `Landmarks` and `MIDI` folders), the HyperCard
User's Guide and the License Information stack. The Windows installers, the AOL
installers and MECC's Windows demos were left behind.

On the title disk that mounts beside the shared Mac OS 8.6 image, the
application file is named "Start App" (with an alias, "Start") so the shared
system can launch it at boot. Only the file's name was changed; its contents
were copied unaltered. The game finds its data beside itself under that name;
driven through the name prompt, a guide, Belém and onto the river on
2026-09-23.
