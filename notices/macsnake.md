# MacSnake (Andreas Hommel, 1998) — Macintosh

## What this is

MacSnake 1.7.1 — a Macintosh snake game. On first run it shows the author's
own note, which is the clearest licence on this site and worth quoting:

> MacSnake 1.1 was Shareware, but I noticed it's kinda stupid to make a small
> game like this shareware because nobody is gonna pay for it anyway. I hope
> people like this game, if you do please let me know in some way.

## Licence

**Freeware, declared by the author in the program itself.** No registration is
asked for and none is owed. The notice is left exactly where it is, including
the author's email address, because it is the licence.

This is the most comfortable position in the catalogue: not an abandonment
argument, not a shareware-distribution argument, but an author saying plainly
that the game is free.

## Provenance

Internet Archive item `tucows_205720_MacSnake`, from the Tucows Macintosh
archive. The `.sit` expands to a plain folder, copied onto a title disk that
mounts beside the shared Mac OS 8.6 image.

On the title disk that mounts beside the shared Mac OS 8.6 image, the
application file is named "Start App" (with an alias, "Start") so the shared
system can launch it at boot. Only the file's name was changed; its contents
were copied unaltered.
