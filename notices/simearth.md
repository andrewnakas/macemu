# SimEarth: The Living Planet (Maxis, 1990) — Macintosh

## What this is

The black-and-white Macintosh release of SimEarth, Will Wright's planetary
simulator, built with James Lovelock's Gaia hypothesis as its model.

## Rights

Maxis was bought by Electronic Arts in 1997 and shut down in 2015. SimEarth has
not been sold in any form for many years and is absent from every current
storefront, EA's own included. Unlike SimCity, no part of it has been released
as open source.

## Provenance

Internet Archive item `SimEarth4amMacCrack` — preserved Macintosh floppies,
copy-protection removed by the preservationist known as 4am. The application
(the build named "SimEarth B&W") and its Planets data file were copied onto a
System 7.5.3 boot disk.

It runs on an emulated Macintosh SE because this is the black-and-white build,
and the compact Mac is the machine it was drawn for.
