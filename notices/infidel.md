# Infidel (Infocom, 1983) — Macintosh

## What this is

Release 22 of Infidel, Michael Berlyn's Egyptian tomb game — the one Infocom shipped with an ending that players wrote in about for years afterwards.

## Rights

Activision owns Infocom's catalogue and still exists, so this is not an orphan
work and is not presented as one.

The narrower point is that Infidel has not been sold since "Classic Text Adventure
Masterpieces of Infocom" went out of print in the late 1990s. Activision has
not offered it in any form since, and it is not part of any current product.

The Zork trilogy is deliberately **not** on this site for the opposite reason:
it is sold today as the Zork Anthology. The line drawn here is what can be
bought now, not what is well known.

## Provenance

Internet Archive item `Infidel4amMacCrack` — a 400K Macintosh floppy, copy protection removed
by the preservationist known as 4am.

The disk keeps its own System and boots on an emulated Macintosh Plus, because
an Infocom interpreter of this vintage resets the machine under System 7.
