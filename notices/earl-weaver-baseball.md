# Earl Weaver Baseball (Electronic Arts, 1988) — Macintosh

## What this is

Earl Weaver Baseball for the Macintosh — the simulation Eddie Dombrower built
with Earl Weaver, the Orioles manager, providing the managerial logic.

## Rights

Electronic Arts owns it and still exists.

There is a second layer: the game is built around a real, named person, under
a licence signed in the 1980s for a product that stopped being sold long ago.
Nothing here should be read as a claim that any likeness or endorsement right
was renewed. Earl Weaver died in 2013 and his estate's rights are its own.

The Macintosh build has not been sold in decades and is in no current product.

## Provenance

Internet Archive item `EarlWeaverBaseball_v15_MacSanIncCrack` — version 1.5 on
a Macintosh floppy, copy protection removed by the preservationist working as
"san inc". The floppy carries no System of its own, so the application was
copied onto a System 7.5.3 boot disk.
