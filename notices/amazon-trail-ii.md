# Amazon Trail II (MECC) — Macintosh CD

## What this is

MECC's Amazon Trail II for Macintosh, version 1.0 (1996, SoftKey Multimedia,
MECC's owner at the time), run here on an emulated Power Macintosh under the
shared Mac OS 8.6 image.

## Rights

The disc carries MECC's standard licence, which does not grant
redistribution. MECC's education catalogue passed from SoftKey to The Learning
Company, Mattel, and eventually Houghton Mifflin Harcourt. Amazon Trail II has
not been sold in any form for well over twenty years and no current product
contains it.

## Why it is hosted

It is the middle Amazon Trail, from the same school labs as The Oregon Trail,
out of commerce for decades and otherwise available only as an abandonware
download. It is hosted on the same footing as this site's other MECC titles:
a practical preservation position, not a legal claim.

## Provenance

Internet Archive item `Amazon_Trail_II_Version_1.0_Softkey_MECC_1996`, file
`Amazon Trail II (Version 1.0)(Softkey)(MECC)(1996).ISO`: a hybrid
Macintosh/Windows CD, volume "Amazon Trail II CD". Onto the title disk went
the Macintosh application (`Data:Mac:Amazon Trail II`, PowerPC) and the game
data it shares with the Windows version (`AMIIDat.mdt`, `AMIIEng.lng`,
`Movies.mov` and the help), side by side, which is how the program finds them.
The Windows executables, DirectX, WinG, QuickTime for Windows, the installer
and MECC's tour were left behind, as were the disc's copies of QuickTime and
the Sound Manager, which the shared Mac OS 8.6 image already carries.

On the title disk that mounts beside the shared Mac OS 8.6 image, the
application file is named "Start App" (with an alias, "Start") so the shared
system can launch it at boot. Only the file's name was changed; its contents
were copied unaltered. Played on 2026-10-02: New Quest, Newcomer, and into
the quest's opening in the museum.
