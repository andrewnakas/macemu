# Oregon Trail II (MECC) — Macintosh CD

## What this is

Oregon Trail II for Macintosh, version 1.32 (copyright 1996, SoftKey
Multimedia, MECC's owner at the time), run here on an emulated Power Macintosh
under the shared Mac OS 8.6 image.

## Rights

The disc carries MECC's standard licence for hybrid CD-ROMs, which does not
grant redistribution. MECC — the Minnesota Educational Computing Consortium —
was privatised in 1991, sold to SoftKey in 1995, folded into The Learning
Company, bought by Mattel in 1999 and sold on in 2000; the education catalogue
eventually reached Houghton Mifflin Harcourt.

Houghton Mifflin Harcourt has licensed the Oregon Trail name for new products
since, among them a 2021 game built from scratch. Oregon Trail II itself has not
been sold in any form for well over twenty years, and no current product
contains it.

## Why it is hosted

It is the 1995 sequel to the most-remembered piece of educational software
ever made, from the same school computer labs, out of commerce for decades and
otherwise available only as an abandonware download. It is hosted on the same
footing as this site's Oregon Trail and The Amazon Trail: a practical
preservation position, not a legal claim.

## Provenance

Internet Archive item `oregon-trail-ii-win-en-win-95-mac-iso`, file
`Oregon-Trail-II_Win_EN_Win95-Mac-ISO.zip`: a hybrid Macintosh/Windows CD
(Apple partition map plus ISO 9660), remastered at some point with Toast 4.1.2.

Only the Macintosh game folder (`Data`) was copied onto the title disk: the
application (`Oregon Trail II`, a fat 68k/PowerPC binary), its data files
(`OregonII.Dat`, `OregonII.dt2`, `OregonII.Eng`, the three `Fst` folders), the
`Movies` folder, the bundled `Saved Games`, and the EHelp user's guide and
help files. The Windows executables in that folder came along with it
unchanged; nothing uses them here. The disc's AOL, Cyber Patrol, registration
and MECC sampler material was left behind, as was the QuickTime installer: the
shared Mac OS 8.6 image already carries QuickTime.

On the title disk that mounts beside the shared Mac OS 8.6 image, the
application file is named "Start App" (with an alias, "Start") so the shared
system can launch it at boot. Only the file's name was changed; its contents
were copied unaltered. The game finds its data beside itself under that name;
driven through Quick Start, the Prologue and onto the trail on 2026-10-01.
