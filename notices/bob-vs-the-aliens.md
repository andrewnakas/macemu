# BOB vs The Aliens (Laurie Murphy / Foxchange Productions, 1997) — Macintosh

## What this is

BOB vs The Aliens 1.4 by Laurie Murphy, published by Foxchange Productions in
1997 — programming and advice by Matt Beedle, ideas by Kendy Sinclair,
programmed in Future BASIC by STAZ Software, all credited on the title screen.

Its stablemate Star Fighters, by the same people, is also on this site.

## Provenance

Internet Archive item `tucows_205593_BOB_vs_The_Aliens`, from the Tucows
Macintosh archive. The `.sit` expands to a plain folder, copied onto a title
disk that mounts beside the shared Mac OS 8.6 image.

On the title disk that mounts beside the shared Mac OS 8.6 image, the
application file is named "Start App" (with an alias, "Start") so the shared
system can launch it at boot. Only the file's name was changed; its contents
were copied unaltered.
