# The Dungeon Revealed (John Raymonds / Woodrose Editions, 1987) — Macintosh

**Hosted:** yes, as `dungeon-revealed-v1`.

## Rights

The Dungeon Revealed was written by John Raymonds and published commercially
by Woodrose Editions in 1987. Its forerunner, The Dungeon of Doom, circulated
as a demo and as shareware. The Dungeon Revealed has not been sold in any form
for decades and no current product contains it.

## Why it is hosted

It is one of the best-remembered games of the black-and-white Macintosh, a
graphical dungeon crawl in the Rogue tradition with a following that has kept
it in circulation as an abandonware download for thirty years. It is hosted
on the same footing as this site's other out-of-commerce 1980s titles: a
practical preservation position, not a legal claim.

## Provenance

Internet Archive item `TheDungeonRevealedMacintosh`, file
`TheDungeonRevealed.img`: an HFS disk holding a System 7 System Folder and the
application. Only the application was copied, unchanged, into Startup Items on
a System 7.5.3 boot disk by `scripts/add-from-archive.py --app-only`; the
disk's own System Folder and its leftover volume-settings folder were left
behind.

Played on 2026-10-01: File > New, a Knight created, onto dungeon level 1, and
moved with the numeric keypad. The page maps the arrow keys to the keypad
(`keymap`), because most keyboards today have no keypad.
