# Bubble Trouble (Ambrosia Software, 1996) — Macintosh

## What this is

Bubble Trouble 1.0.1, written by Alex Metcalf and David Wareing, published by Ambrosia Software, exactly as the Ambrosia
installer produced it.

## Licence

Ambrosia shareware, under the same agreement as the other Ambrosia titles
here. The licence file that ships with the game (`Bubble Trouble License.text`) reads, in part:

> Non-profit distribution of the software is acceptable without prior written
> notice, providing that the software is not modified in any way, and the
> complete works of the software are included in the distribution package.

Both conditions are met: the copy is what the installer wrote, and the
unregistered shareware notice is left where it is. The permission is for
*non-profit* distribution. **If macemu ever carries advertising, these have to
be revisited.**

## Provenance

Internet Archive item `ambrosia_software_cd_7`: Ambrosia Software CD 7, the
company's own compilation disc (a raw MODE1 CD image, one HFS volume "Ambrosia
CD 7"). The installer there is an Installer VISE archive; it was run inside
emulated Mac OS 8.6 on 2026-09-25 and the result taken back out (see
`scripts/steps/ambrosia-batch2.json` and `scripts/steps/ares.json`).

On the title disk that mounts beside the shared Mac OS 8.6 image, the
application file is named "Start App" (with an alias, "Start") so the shared
system can launch it at boot. Only the file's name was changed; its contents
were copied unaltered. Driven into actual play before the page was written.
