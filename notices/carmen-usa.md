# Where in the USA is Carmen Sandiego? (Brøderbund, 1996) — Macintosh CD

## What this is

Version 3.0.2 of *Where in the USA is Carmen Sandiego?* for Macintosh and
Power Macintosh, © 1996 Brøderbund Software. Its readme, dated 20 January 1997,
says this build was configured for the Apple Performa and Power Macintosh
models it was bundled with. It runs here on an emulated Power Macintosh under
the shared Mac OS 8.6 image.

## Rights

The same position as the two other Carmen Sandiego titles on this site, stated
the same way.

Brøderbund was acquired by The Learning Company in 1998, and Carmen Sandiego
now belongs to Houghton Mifflin Harcourt, which has licensed it actively for
new work: a Netflix animated series in 2019 and new games alongside it.

Those are new software. This 1996 CD edition has not been sold by anyone in
over twenty-five years and is contained in no current product. The argument
is about this specific artefact being out of commerce, not about the name
being free, and the name plainly is not.

## Provenance

Internet Archive item `carmen-sandiego-usa`: a plain HFS CD image, volume
"Carmen Sandiego USA".

The disc was installed the way its readme describes: the CD's own installer
was run inside the emulated Mac (Mac OS 8.6, with an empty work disk and the
CD mounted), and the installed folder became the small title disk. That disk
holds the application, its `MOHAWK.PPC` engine file, `music.dat` and the readme.

The game reads its photographs, video and speech from the CD while it runs,
and it finds the CD by its volume name, so the whole disc is mounted beside
it, unaltered.

On the title disk, the application file is named "Start App" (with an alias,
"Start") so the shared system can launch it at boot. Only the file's name was
changed; its contents are as the installer wrote them. The game was played
from the ACME roster through the Chief's briefing to the first destination on
2026-09-27.
