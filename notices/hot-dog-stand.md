# Hot Dog Stand: The Works (Sunburst Communications) — Macintosh CD

## What this is

Hot Dog Stand: The Works for Macintosh, version 1.1, Sunburst Communications'
school business-and-maths simulation, run here on an emulated Power Macintosh
under the shared Mac OS 8.6 image.

## Rights

Sunburst Communications published Hot Dog Stand: The Works for schools in the
1990s. This CD release has not been sold for well over twenty years, and no
current product contains it.

## Why it is hosted

It is one of the school computer lab programs people remember by name, out of
commerce for decades and otherwise available only as an abandonware download.
It is hosted on the same footing as this site's MECC titles: a practical
preservation position, not a legal claim.

## Provenance

Internet Archive item `hot-dog-stand-the-works`, file
`Hot Dog Stand - The Works (1998)(Sunburst).iso`: a hybrid Macintosh/Windows
CD. Only the Macintosh `Hot Dog Stand ƒ` folder was copied onto the title disk:
the application (PowerPC), its `Game Files`, `RES` and `Preferences`, the help
file and the Microsoft Help runtime it uses. The disc's installer and its
copy of QuickTime and the Sound Manager were left behind; the shared Mac OS 8.6
image already carries both.

On the title disk that mounts beside the shared Mac OS 8.6 image, the
application file is named "Start App" (with an alias, "Start") so the shared
system can launch it at boot. Only the file's name was changed; its contents
were copied unaltered. Played on 2026-10-01: signed in, chose Beginner, and
reached the office with the day's specials and the stand.
