# Mighty Mike (Pangea Software, 1997) — Macintosh

## What this is

Mighty Mike, Brian Greenstone's Pangea Software action game — the shareware
release of the game published commercially by MacPlay as **Power Pete**.

On startup it says the copy is not registered and offers a Demo button, which
plays. That notice is the author's and is left exactly as it is.

## Licence

Shareware. Pangea distributed Mighty Mike freely in this form, with
registration asked for and a demo mode for people who had not paid.

Pangea Software still exists and Brian Greenstone is reachable and active.
That matters: this is not an orphan work, and it is hosted on the ordinary
shareware distribution model — an unregistered, unmodified copy showing its
own nag — rather than on any abandonment argument.

Power Pete, the commercial MacPlay release of the same game, is a different
distribution and is **not** what is here.

## Provenance

Internet Archive item `tucows_205686_Mighty_Mike`, from the Tucows Macintosh
archive. The `.sit` expands to a plain folder, copied onto a title disk that
mounts beside the shared Mac OS 8.6 image.

On the title disk that mounts beside the shared Mac OS 8.6 image, the
application file is named "Start App" (with an alias, "Start") so the shared
system can launch it at boot. Only the file's name was changed; its contents
were copied unaltered.
