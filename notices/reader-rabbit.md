# Reader Rabbit (The Learning Company, 1987) — Macintosh

## What this is

Version 2.0 of the Macintosh Reader Rabbit, with all four games and MacinTalk
speech.

## Rights

The Learning Company was founded in 1980, sold to SoftKey in 1995, and the name
then travelled through Mattel, Gores Technology and Houghton Mifflin Harcourt.
Reader Rabbit products have been published throughout. Those are new software;
this Macintosh build has not been sold in over thirty years.

## MacinTalk

The original floppy carried MacinTalk beside the application — Apple's 1984
speech synthesiser, which Reader Rabbit uses to read words aloud. Apple
distributed MacinTalk freely with system software and developer materials for
years. It has been installed into the System Folder of the boot disk here so
that the speech works, which is how the program was meant to run.

## Provenance

Internet Archive item `ReaderRabbit4amMacCrack` — a preserved Macintosh floppy,
copy-protection removed by the preservationist known as 4am. The floppy's own
System file was dropped; MacinTalk was kept.

One repair was needed: the application on the original disk has the Finder's
alias bit set on itself. That was harmless on a floppy that booted straight into
it, and under System 7 the Finder reads the flag first and refuses to open the
program at all. The flag is cleared. Nothing else about the file was touched.
