# Arashi — provenance and licence

**Hosted:** yes, as `arashi-v1`.
**Provenance:** shareware, redistributed under the terms its authors published.

## Where the files came from

The MacSilverWare shareware CD-ROM, preserved at the Internet Archive as
[`macsilverware`](https://archive.org/details/macsilverware), at
`Games:Arcade:Arashi 1.1`. Copied into a System 7.5.3 boot image by
`scripts/build-title-image.py`. The complete folder is included: the
application, the ReadMe, the note about the source, and the C source itself,
which the authors shipped with the game.

## Why it can be here

`Arashi 1.1 ReadMe`, which is on the disk we serve, states the terms in one
line:

> ARASHI is freely distributable as long as it is not for profit.

Both halves are honoured. Nothing is modified — the application, its data and
its documentation are copied byte for byte — and macemu carries no advertising.

The authors add that anyone distributing it on CD-ROM might send them a
complimentary copy. That is a request rather than a condition, and it is from
1993; there is no address left to send one to.

## The one open question

Should this site ever carry advertising, "not for profit" needs revisiting
rather than assuming. The safest reading is that shareware titles stay out of
any ad-carrying layout. The same note applies to `notices/maelstrom.md`.
