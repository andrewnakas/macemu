# Space Debris (Richard Bannister, 1997) — Macintosh

## What this is

Space Debris v2.5 by Richard Bannister — a Macintosh asteroids-style shooter,
in colour, PowerPC build.

## Licence

Shareware. The copy here is unregistered and unmodified, with the author's
registration notice left where he put it.

Richard Bannister is still active in Macintosh software and has released much
of his older work freely over the years. No specific grant covering this build
has been located; it is here on the ordinary shareware distribution model, and
because he is reachable, a request from him is the easiest possible takedown.

## Provenance

Internet Archive item `tucows_205653_Space_Debris`, from the Tucows Macintosh
archive. The `.sit` expands to a plain folder, copied onto a small title disk
that mounts beside the shared Mac OS 8.6 image.

On the title disk that mounts beside the shared Mac OS 8.6 image, the
application file is named "Start App" (with an alias, "Start") so the shared
system can launch it at boot. Only the file's name was changed; its contents
were copied unaltered.
