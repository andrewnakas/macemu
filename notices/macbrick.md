# MacBrick (Macintosh shareware, 1997)

## What this is

MacBrick, PowerPC shareware build — a brick-breaker for the classic Macintosh.

**This is the shareware version and it contains five levels.** The program
says so itself on startup: "This is the shareware version of MacBrick. It only
contains 5 levels. To get more levels, you have to order the full version!"
That notice is the author's and is left exactly where it is.

## Licence

Shareware, distributed freely in this limited form. The copy here is
unregistered and unmodified — the level limit and the notice announcing it are
both intact, because removing either would be modifying the software.

The full version was sold and is not here.

## Provenance

Internet Archive item `tucows_205604_MacBrick`, from the Tucows Macintosh
archive. The `.sit` expands to a plain folder, copied onto a title disk that
mounts beside the shared Mac OS 8.6 image.

On the title disk that mounts beside the shared Mac OS 8.6 image, the
application file is named "Start App" (with an alias, "Start") so the shared
system can launch it at boot. Only the file's name was changed; its contents
were copied unaltered.
