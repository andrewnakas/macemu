# Mac OS 8.6 (Apple, 1999)

## What this is

A complete Mac OS 8.6 installation — the last release of the Mac OS 8 line,
from May 1999 — booting on an emulated Power Macintosh 9500 under SheepShaver.

## Rights

Mac OS 8.6 is Apple's and Apple is very much still in business, so this is a
deliberate decision rather than a lookup.

Apple has not sold Mac OS 8.6 in over twenty years. It runs on no machine
Apple makes, is contained in no current product, and has no modern equivalent
that it competes with. Classic Apple system software — System 6, System 7,
Mac OS 8 and 9, and the ROMs they need — has been distributed openly by the
Internet Archive, Macintosh Garden, Infinite Mac and E-Maculation for many
years without objection from Apple.

That is not a licence, and it is not claimed as one. It is the basis on which
this is hosted, stated plainly so that anyone who disagrees knows exactly what
to object to.

## Provenance

Internet Archive item `mac-os-86` — a 500 MB pre-installed hard disk image
prepared for SheepShaver. The item is titled "Mac OS 8"; the System file and
the boot splash both report **8.6**, which is what the pages say.

**The image was cleaned before use.** Whoever built it had left third-party
software on the disk: Fraction Muncher, Odell Down Under and an Oregon Trail
release, plus installer logs. Those are MECC titles that have not been through
the provenance check every other title on this site gets, and shipping them
inside a system image would be hosting them by the back door. They were removed,
along with the desktop aliases pointing at them, before the image was chunked.
What remains is Apple's own system software and the applications Apple shipped
with it.
