# MacWrite (Apple, 1984) — Macintosh

## What this is

MacWrite, the word processor that shipped free with the Macintosh from 1984.

## Rights

MacWrite is Apple's, and Apple is still in business, so this needs the same
care as MacPaint — with one difference worth stating plainly.

The MacPaint case is helped by Apple having given that program's source to the
Computer History Museum in 2010 to publish. **That release covered MacPaint and
QuickDraw. It did not cover MacWrite.** The argument here therefore rests on
abandonment alone: Apple spun the product out to Claris, which shipped MacWrite
II and MacWrite Pro and then discontinued the line in the 1990s. Nothing in the
lineage has been sold in over thirty years and no current product contains it.

It is hosted because MacWrite and MacPaint were the two programs in the box, and
the case each made for the machine only really lands when you can open them
both.

## Provenance

Internet Archive item `mac_MacWrite` — a 400K floppy. The application was copied
onto a System 7.5.3 boot disk; the floppy's own System was dropped.

## Takedown

without argument and without asking for an explanation.
