# System 7.5.3 (Apple, 1996)

## What this is

A bare System 7.5.3 installation booting to its own desktop on an emulated
Macintosh II under Mini vMac, in colour. It is the same disk the file-loader
pages boot (`system-7.5.3` in `public/mac/disks/`), run here on its own so the
operating system itself can be looked at.

## Rights

System 7.5.3 is Apple's, and Apple is very much still in business, so this is a
deliberate decision rather than a lookup.

Apple itself published System 7.5.3 as a free download from its own servers in
the late 1990s, and later releases of the classic Mac OS were the subject of
the same open distribution by the Internet Archive, Macintosh Garden, Infinite
Mac and E-Maculation for many years without objection from Apple. It has not
been sold in nearly thirty years, runs on no machine Apple makes, and is
contained in no current product.

That is not a licence, and it is not claimed as one. It is the basis on which
this is hosted, stated plainly so that anyone who disagrees knows exactly what
to object to.

## Provenance

A bare 20 MB HFS image of System 7.5.3 from the Internet Archive, the same
image the site has booted since its first working machine (commit 764ab80).
What is on it is Apple's: the System Folder, SimpleText, the Apple Extras
folder, the Apple menu items that shipped with 7.5, and ResEdit 2.1.3, Apple's
own free resource editor.

The page runs it without saving anything: every visit starts from the same
clean disk.

## Takedown

If Apple wants it gone, say so at /takedown/ and it is removed within 48 hours,
without argument and without asking for an explanation.
