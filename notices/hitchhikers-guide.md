# The Hitchhiker's Guide to the Galaxy (Infocom, 1984) — Macintosh

## What this is

Release 47 of Infocom's text adventure, written by Douglas Adams and Steve
Meretzky, on its Macintosh floppy.

## Rights

Infocom's catalogue passed to Activision, which still exists and still owns it.
This is not an ownerless work and is not presented as one.

What can be said is narrower. Hitchhiker's has not been sold since "Classic
Text Adventure Masterpieces of Infocom" went out of print in the late 1990s.
Activision has not offered it since. The BBC published a free browser version
in 2004 for the radio series' anniversary, with Activision's involvement — that
is a different implementation and is not this disk, but it is a fair indication
of how commercially live the property is considered to be.

The Zork trilogy is deliberately **not** here for the opposite reason: it is
sold today, as the Zork Anthology, and anything currently on sale stays off
this site.

## Provenance

Internet Archive item `TheHitchhikersGuideToTheGalaxy4amMacCrack` — a 400K
Macintosh floppy, copy protection removed by the preservationist known as 4am.

The disk keeps its own System and boots on an emulated Macintosh Plus. The
application on it is named "Hitchhiker's Guide"; the boot blocks that name the
startup program hold only fifteen characters, so on this copy the file is
called "Hitchhiker's Gu". Nothing else was changed, and the game never shows
you a Finder in which the shortened name would appear.
