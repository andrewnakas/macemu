# Legends of the Lost Realm I: The Gathering of Heroes (Avalon Hill, 1988) — Macintosh

## What this is

Version 2.0 of Legends of the Lost Realm I, published by The Avalon Hill Game
Company — a party-based Macintosh role-playing game by Ronald Coleman.

On startup it asks which drive holds the "Gathering of Heroes" scenario data.
The data is on this disk; choose the hard disk.

## Rights

Avalon Hill's game division was bought by Hasbro in 1998, and Hasbro still
exists. The Avalon Hill name is in current use for boardgames.

The computer-game catalogue that came with that purchase has not been
published since, and no Hasbro or Avalon Hill product contains this Macintosh
program. It has not been purchasable in about thirty-five years.

## Provenance

Internet Archive item `LegendsOfTheLostRealmI4amMacCrack` — a Macintosh floppy,
copy protection removed by the preservationist known as 4am.

The floppy's own System would not start the game on an emulated Macintosh
Plus, so the application and its data were copied onto a System 7.5.3 boot
disk instead.
