# Amazon Trail 3rd Edition: Rainforest Adventures — Macintosh (General Mills CD)

## What this is

Amazon Trail 3rd Edition: Rainforest Adventures, version 1.1 (© 2000 Mattel,
Inc.), the third version of MECC's Amazon Trail, run here on an emulated Power
Macintosh under the shared Mac OS 8.6 image.

## Rights

The game came to Mattel with The Learning Company and the MECC catalogue, and
the education catalogue eventually reached Houghton Mifflin Harcourt. This copy
is the one General Mills gave away free, in full, on a promotional CD-ROM
("LightDog") in 2000. That was a giveaway, not a licence to pass it on, and the
disc grants no redistribution. The game has not been sold in any form for over
twenty years and no current product contains it.

## Why it is hosted

It is the last of the Amazon Trail games, from the same school labs as The
Oregon Trail, out of commerce for decades and otherwise available only as an
abandonware download. It is hosted on the same footing as this site's other
MECC titles: a practical preservation position, not a legal claim.

## Provenance

Internet Archive item `generalmills`, file `generalmills.iso`: a hybrid
Macintosh/Windows CD, volume "LightDog". Only the Macintosh game's `Data`
folder (inside `Amazon`) was copied onto the title disk: the application
(`Amazon 3.1`, PowerPC), `AMIIDat.mdt`, `AMIIEng.Lng`, `Billboards.mdt`,
`Movies.mov` and the help. Two Windows files in that folder came along
unchanged and are unused. The disc's Lightdog launcher, Acrobat Reader,
registration, QuickTime installer and the other promotional material were
left behind.

On the title disk that mounts beside the shared Mac OS 8.6 image, the
application file is named "Start App" (with an alias, "Start") so the shared
system can launch it at boot. Only the file's name was changed; its contents
were copied unaltered. Played on 2026-10-02: New Quest, Novice, the opening
river film, and into Belém, where the Amazon River Tours shop asks you to pick
a guide.
