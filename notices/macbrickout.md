# MacBrickout (Leapfrog Software, 1999) — Macintosh

## What this is

MacBrickout 4.1, with its three level packs, as distributed.

## Licence

Shareware. The game is distributed freely and is fully playable; it shows a
registration notice at startup asking $25 if you keep it. That is the entire
model, and distributing the unregistered program is what shareware
distribution means.

The copy here is unmodified. The registration notice is still there and the
registration number it displays is the one the program generates for itself,
not anybody's licence key. Nothing has been patched or pre-registered.

## Provenance

Internet Archive item `tucows_205650_MacBrickout`, from the Tucows Macintosh
archive — `macbrickout.sit`, which expands to a plain folder rather than an
installer, so no emulator run was needed. The folder was imported whole,
including the level packs, the localisation files and the author's development
log.

One repair was needed on the way in: macOS stores filenames decomposed, so an
accented name arrives as a letter followed by a combining mark, and MacRoman
has no code point for a combining mark. The names are composed back to the
single characters the Mac originally used.

On the title disk that mounts beside the shared Mac OS 8.6 image, the
application file is named "Start App" (with an alias, "Start") so the shared
system can launch it at boot. Only the file's name was changed; its contents
were copied unaltered.
