# MacPaint (Apple, 1984) — Macintosh

## What this is

MacPaint 1.5, Bill Atkinson's paint program, which shipped with the Macintosh
from 1984.

## Rights

MacPaint is Apple's, and Apple is still very much in business. That makes this
a more considered decision than most entries here, and the reasoning is worth
stating in full.

In July 2010 Apple gave the source code of MacPaint 1.3, together with
QuickDraw, to the Computer History Museum, which published it under a licence
permitting non-commercial use. Apple does not do that with software it
considers commercially live. It is the clearest public signal available about
how Apple regards this particular program today.

The application has not been sold or distributed by Apple in over thirty-five
years, is contained in no current product, and has no modern equivalent that it
competes with. It is hosted here because it is arguably the single most
historically important application the Macintosh ever had, and because being
able to open it and draw is a different kind of understanding from reading
about it.

## Provenance

Internet Archive item `mac_Paint_2` — a 400K MFS floppy. The application was
copied onto a System 7.5.3 boot disk; the floppy's own System and Finder were
dropped, and its ImageWriter driver, Note Pad and Scrapbook files were filed
into the System Folder.
