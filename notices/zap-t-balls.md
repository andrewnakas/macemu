# Zap'T'Balls II (Macintosh shareware, 1994–2002)

## What this is

Zap'T'Balls II v2.5, by Richard F. Bannister — a Macintosh arcade game in the
style of Pang / Super Buster Bros.: split bouncing balls with a harpoon until
none are left.

## Rights

Worth naming: **Pang is Mitchell Corporation's** and has been re-released.
This is not that game. It is an independently written Macintosh shareware
title in the same genre, with its own code and its own (photographic) artwork,
built on Ingemar Ragnemalm's freely available Sprite Animation Toolkit.

As software it is shareware, distributed by its author through the shareware
archives. This copy is the unregistered v2.5 release, unmodified, with its
Read Me, "Software by RFB" and Register application included. Registration was
through Kagi, which has since closed. The same author's Space Debris is also on
this site, on the same footing.

## Provenance

Internet Archive item `tucows_205652_Zap_T_Balls_II`, from the Tucows Macintosh
archive. The `.sit` expands to a plain folder, copied onto a title disk that
mounts beside the shared Mac OS 8.6 image.
On that disk the application file is named "Start App" (with an alias,
"Start") so the shared system can launch it at boot; its contents are
byte-for-byte the archived original.
