# Sphaera (Macintosh freeware, 1999)

## What this is

Sphaera v1.0.1, by Shawn Henry — a freeware Breakout game for PowerPC
Macintoshes, released in August 1999.

## Rights

Freeware. The readme's "Legalese" section:

> Sphaera is Freeware, but is © 1999 by Shawn Henry. Distribution by
> nonprofit groups or online distribution by online services or BBSs is
> permitted as long as this documentation is included unchanged.

This site is non-profit, carries no advertising and distributes online. The
readme, "Sphaera Homepage" and "Contact The Author" files are on the title disk
unchanged, and the game itself is unmodified.

## Provenance

Internet Archive item `tucows_205674_Sphaera`, from the Tucows Macintosh
archive. The `.sit` expands to a plain folder, copied onto a title disk that
mounts beside the shared Mac OS 8.6 image.
On that disk the application file is named "Start App" (with an alias,
"Start") so the shared system can launch it at boot; its contents are
byte-for-byte the archived original.
